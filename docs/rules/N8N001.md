# N8N001: Hardcoded secret in Code or HTTP node

- Severity: **critical**
- Category: Security
- Disable: `--disable N8N001` or put `n8n-lint-disable N8N001` in the node's Notes field.

## Why it matters

Workflow JSON is routinely pasted into forums, tickets and git. A key typed into a header or Code node travels with the export.

## What triggers it

Hardcoded secret in a Code/HTTP node.

## Example

Flagged:

```
{ "name": "Authorization", "value": "Bearer <a 30+ character literal token>" }
```

Better:

```
{ "name": "Authorization", "value": "={{ 'Bearer ' + $env.API_TOKEN }}" }
```

## How to fix

Move the value into an n8n credential or an environment variable and reference it by expression; rotate the exposed secret.
