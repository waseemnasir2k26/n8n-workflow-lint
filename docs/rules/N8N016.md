# N8N016: $input.first() without a guard

- Severity: **medium**
- Category: Reliability
- Disable: `--disable N8N016` or put `n8n-lint-disable N8N016` in the node's Notes field.

## Why it matters

When the previous node returns zero items, $input.first() is undefined and the Code node throws, killing the run.

## What triggers it

Code node reads $input.first() with no empty-input guard.

## Example

Flagged:

```
const id = $input.first().json.id;
```

Better:

```
const first = $input.first(); if (!first) return [];
```

## How to fix

Check `$input.all().length` first, or use optional chaining: `$input.first()?.json`.
