# N8N002: pinData leaked in the export

- Severity: **high**
- Category: Security
- Disable: `--disable N8N002` or put `n8n-lint-disable N8N002` in the node's Notes field.

## Why it matters

Pinned data is real execution output. It often contains customer emails, tokens and API responses.

## What triggers it

Export contains pinData (saved sample data).

## Example

Flagged:

```
{ "pinData": { "Webhook": [ { "json": { "email": "..." } } ] } }
```

Better:

```
{ "nodes": [ ... ], "connections": { ... } }
```

## How to fix

Unpin data in the editor (or delete the "pinData" key) before sharing or committing the workflow.
