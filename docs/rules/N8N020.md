# N8N020: AI Agent without a sane iteration cap

- Severity: **high**
- Category: AI cost
- Disable: `--disable N8N020` or put `n8n-lint-disable N8N020` in the node's Notes field.

## Why it matters

An agent that keeps calling tools can loop on every failure. The iteration cap is the cheapest circuit breaker you have.

## What triggers it

AI Agent has no explicit maxIterations or it is above 10.

## Example

Flagged:

```
{ "type": "@n8n/n8n-nodes-langchain.agent", "parameters": { "options": {} } }
```

Better:

```
{ "type": "@n8n/n8n-nodes-langchain.agent", "parameters": { "options": { "maxIterations": 5 } } }
```

## How to fix

Set Options -> Max Iterations to a small number (3-5 for most agents; never above 10).
