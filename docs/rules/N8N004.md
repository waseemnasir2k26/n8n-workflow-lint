# N8N004: Credential referenced by instance id/name, not placeholder

- Severity: **info**
- Category: Security
- Disable: `--disable N8N004` or put `n8n-lint-disable N8N004` in the node's Notes field.

## Why it matters

Credential ids and names reveal how your instance is wired and break on import. Shared templates should use placeholders.

## What triggers it

Node references an instance-specific credential.

## Example

Flagged:

```
{ "credentials": { "slackApi": { "id": "Qx81aB", "name": "Acme prod Slack" } } }
```

Better:

```
{ "credentials": { "slackApi": { "id": "REPLACE_ME", "name": "REPLACE_ME" } } }
```

## How to fix

Before sharing the workflow as a template, replace credential ids/names with placeholders (or strip the "credentials" key).
