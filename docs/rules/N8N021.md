# N8N021: Retry path loops back into an LLM node

- Severity: **high**
- Category: AI cost
- Disable: `--disable N8N021` or put `n8n-lint-disable N8N021` in the node's Notes field.

## Why it matters

A hand-wired retry that re-enters an LLM node has no built-in ceiling, so every failure becomes another paid call.

## What triggers it

A connection cycle passes through an LLM/Agent node.

## Example

Flagged:

```
LLM Call -> IF failed? -> (true) -> LLM Call
```

Better:

```
LLM Call (Retry On Fail, maxTries 3) -> IF failed? -> Alert
```

## How to fix

Break the cycle: cap attempts with a counter and an IF, or use node-level Retry On Fail (bounded by maxTries) instead of wiring a loop.
