# N8N011: HTTP Request without retry or timeout

- Severity: **medium**
- Category: Reliability
- Disable: `--disable N8N011` or put `n8n-lint-disable N8N011` in the node's Notes field.

## Why it matters

Remote APIs fail transiently. A missing timeout can hang an execution; a missing retry turns a blip into a failed run.

## What triggers it

HTTP Request has no retry/timeout.

## Example

Flagged:

```
{ "type": "n8n-nodes-base.httpRequest", "parameters": { "url": "https://api.example.com" } }
```

Better:

```
{ "type": "n8n-nodes-base.httpRequest", "retryOnFail": true, "maxTries": 3, "parameters": { "options": { "timeout": 30000 } } }
```

## How to fix

Enable "Retry On Fail" (3 tries, 2-5 s wait) and set Options -> Timeout (e.g. 30000 ms).
