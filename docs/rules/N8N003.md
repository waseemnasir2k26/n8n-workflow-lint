# N8N003: Webhook with no authentication

- Severity: **high**
- Category: Security
- Disable: `--disable N8N003` or put `n8n-lint-disable N8N003` in the node's Notes field.

## Why it matters

A public production URL with authentication "none" lets anyone on the internet trigger your workflow and spend your API credits.

## What triggers it

Webhook node accepts unauthenticated requests.

## Example

Flagged:

```
{ "type": "n8n-nodes-base.webhook", "parameters": { "path": "orders" } }
```

Better:

```
{ "type": "n8n-nodes-base.webhook", "parameters": { "path": "orders", "authentication": "headerAuth" } }
```

## How to fix

Set Authentication to Header Auth / Basic Auth / JWT on the Webhook node, or verify a signature in the first node.
