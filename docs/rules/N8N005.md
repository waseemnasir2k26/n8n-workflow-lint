# N8N005: TLS certificate validation disabled

- Severity: **medium**
- Category: Security
- Disable: `--disable N8N005` or put `n8n-lint-disable N8N005` in the node's Notes field.

## Why it matters

Disabling certificate checks removes the guarantee that you are talking to the intended server.

## What triggers it

HTTP Request ignores invalid TLS certificates.

## Example

Flagged:

```
{ "parameters": { "options": { "allowUnauthorizedCerts": true } } }
```

Better:

```
{ "parameters": { "options": {} } }
```

## How to fix

Turn off "Ignore SSL Issues" and install the correct CA certificate or fix the endpoint certificate.
