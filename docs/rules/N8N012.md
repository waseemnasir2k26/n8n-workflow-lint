# N8N012: Loop with no exit branch

- Severity: **medium**
- Category: Reliability
- Disable: `--disable N8N012` or put `n8n-lint-disable N8N012` in the node's Notes field.

## Why it matters

A batch loop whose finished branch goes nowhere never hands results on, and a mis-wired loop can run forever.

## What triggers it

Loop Over Items has no exit ("done") branch.

## Example

Flagged:

```
{ "type": "n8n-nodes-base.splitInBatches", "typeVersion": 3 }  // output 0 unconnected
```

Better:

```
Connect output 0 ("done") to a downstream node.
```

## How to fix

Connect the "done" output (output 0 in Loop Over Items v3) to the next step, so the loop can finish and continue.
