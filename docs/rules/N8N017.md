# N8N017: No trigger node

- Severity: **medium**
- Category: Reliability
- Disable: `--disable N8N017` or put `n8n-lint-disable N8N017` in the node's Notes field.

## Why it matters

A workflow with no trigger never runs on its own, so a "scheduled" automation silently does nothing.

## What triggers it

Workflow has no trigger node.

## Example

Flagged:

```
nodes: [ HTTP Request, Set ]
```

Better:

```
nodes: [ Schedule Trigger, HTTP Request, Set ]
```

## How to fix

Add a Schedule, Webhook or other trigger, or mark the workflow as a sub-workflow with an Execute Workflow Trigger.
