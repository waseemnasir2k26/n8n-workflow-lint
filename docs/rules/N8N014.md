# N8N014: Default node names

- Severity: **low**
- Category: Reliability
- Disable: `--disable N8N014` or put `n8n-lint-disable N8N014` in the node's Notes field.

## Why it matters

Names like "HTTP Request1" make errors, execution logs and expressions ($('HTTP Request1')) impossible to read at 3am.

## What triggers it

Nodes still carry default names.

## Example

Flagged:

```
{ "name": "HTTP Request1" }
```

Better:

```
{ "name": "Fetch Open Invoices" }
```

## How to fix

Rename nodes to say what they do ("Fetch Orders", "Is VIP?"). Expressions that reference them become readable.
