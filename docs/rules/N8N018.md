# N8N018: Disabled nodes left in workflow

- Severity: **info**
- Category: Reliability
- Disable: `--disable N8N018` or put `n8n-lint-disable N8N018` in the node's Notes field.

## Why it matters

Disabled nodes rot: nobody remembers why they exist or whether re-enabling them is safe.

## What triggers it

Workflow contains disabled nodes.

## Example

Flagged:

```
{ "name": "Old Notify", "disabled": true }
```

Better:

```
Remove the node.
```

## How to fix

Delete experiments you are done with; keep the history in git instead of in the canvas.
