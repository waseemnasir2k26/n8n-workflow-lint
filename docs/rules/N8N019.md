# N8N019: Execute Command node

- Severity: **medium**
- Category: Reliability
- Disable: `--disable N8N019` or put `n8n-lint-disable N8N019` in the node's Notes field.

## Why it matters

Shell execution plus expression input is a command-injection path, and n8n Cloud does not allow the node at all.

## What triggers it

Execute Command runs shell commands on the n8n host.

## Example

Flagged:

```
{ "type": "n8n-nodes-base.executeCommand" }
```

Better:

```
Use an HTTP Request to a small internal service instead.
```

## How to fix

Replace it with a dedicated node, an HTTP call to a service, or a sandboxed worker. If you must keep it, never interpolate user input.
