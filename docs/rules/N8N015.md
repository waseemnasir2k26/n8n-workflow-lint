# N8N015: Deprecated node typeVersion

- Severity: **low**
- Category: Reliability
- Disable: `--disable N8N015` or put `n8n-lint-disable N8N015` in the node's Notes field.

## Why it matters

Old node versions miss bug fixes and options, and replaced node types are eventually removed.

## What triggers it

Node uses an outdated typeVersion or a replaced node type.

## Example

Flagged:

```
{ "type": "n8n-nodes-base.httpRequest", "typeVersion": 1 }
```

Better:

```
{ "type": "n8n-nodes-base.httpRequest", "typeVersion": 4.2 }
```

## How to fix

Re-add the node from the node panel (or open and re-save it in a current n8n) so it picks up the current version.
