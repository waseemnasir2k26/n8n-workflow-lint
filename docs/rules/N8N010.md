# N8N010: No error workflow

- Severity: **high**
- Category: Reliability
- Disable: `--disable N8N010` or put `n8n-lint-disable N8N010` in the node's Notes field.

## Why it matters

Without an error workflow, production failures are silent until a customer tells you.

## What triggers it

No Error Workflow is configured and there is no Error Trigger.

## Example

Flagged:

```
{ "settings": {} }
```

Better:

```
{ "settings": { "errorWorkflow": "<id of your error workflow>" } }
```

## How to fix

Set Settings -> Error Workflow to a workflow that starts with an Error Trigger and alerts you (Slack, email).
