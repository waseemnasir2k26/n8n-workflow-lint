# N8N013: Orphan or disconnected node

- Severity: **low**
- Category: Reliability
- Disable: `--disable N8N013` or put `n8n-lint-disable N8N013` in the node's Notes field.

## Why it matters

Dead nodes hide stale logic and mislead the next person who edits the workflow.

## What triggers it

Node is not connected to the workflow.

## Example

Flagged:

```
A node with no incoming or outgoing connection.
```

Better:

```
Every active node sits on a path from a trigger.
```

## How to fix

Connect the node, or delete it. Disable it only if you plan to use it again.
