# N8N023: High estimated monthly LLM token cost

- Severity: **low**
- Category: AI cost
- Disable: `--disable N8N023` or put `n8n-lint-disable N8N023` in the node's Notes field.

## Why it matters

Agent loops multiply calls. The estimate is a deliberate upper bound (every agent uses its full iteration budget) so you see worst-case exposure before production does.

## What triggers it

Estimated monthly token cost exceeds the budget threshold.

## Example

Flagged:

```
AI Agent, maxIterations 10, claude-3-opus, 100 runs/day
```

Better:

```
AI Agent, maxIterations 4, gpt-4o-mini
```

## How to fix

Lower maxIterations, route simple steps to a cheaper model, or add a spend cap at the provider. Tune with --runs-per-day and --cost-threshold.
