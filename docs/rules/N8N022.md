# N8N022: HTTP error output wired back into an agent

- Severity: **high**
- Category: AI cost
- Disable: `--disable N8N022` or put `n8n-lint-disable N8N022` in the node's Notes field.

## Why it matters

An agent that receives a 404/500 as fresh input tends to retry the same tool call. One community report describes this pattern costing $300 in about 30 minutes.

## What triggers it

An HTTP Request error output feeds an AI Agent.

## Example

Flagged:

```
HTTP Request (On Error: continue using error output) -[error]-> AI Agent
```

Better:

```
HTTP Request -[error]-> Stop and Error
```

## How to fix

Send the error output to an alert/stop path (Stop and Error, Slack), not back into the agent. Cap agent iterations (N8N020).
